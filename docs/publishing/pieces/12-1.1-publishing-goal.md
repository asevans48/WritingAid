## The piece

- **Decided:** the goal is a publishable manuscript, and the one fact the writer
  sets is the **route**: agent submission or self-publishing. Length is not a
  target.
- **The writer gets:** one extra field beside the genre in the prose profile:
  the route. It has a default, so it can be ignored. A novella can have its
  own route.
- **What the route changes:** how strict the opening-pages check is (1.8), which
  export is offered first (9.2), and what the submission package contains
  (9.3).
- **Length:** shown as information beside what is typical for the genre and
  route, per manuscript, so a novella is compared with novellas. It is never
  a pass or fail and never counts toward readiness.
- **Storage:** the route is kept per manuscript in the project's readiness file
  (see 1.2a), not inside the prose profile. A field added inside the prose
  profile would be dropped if an older version of the app saved the project
  (rule 11). With no file, the default route applies.
- **Build:** the route setting; a small
  `publishing_goal` helper that returns genre, route and the typical length
  range, with defaults when nothing is set.
- **Check first:** the Publishing tab (`src/ui/agent_manager_widget.py`) already
  deals with agents and with publishing to Kindle and Barnes & Noble. If the
  route fits better there than beside the genre, put it there; either way it
  is asked once.
- **Read first:** `ProseProfile` in `src/models/project.py`,
  `src/ui/prose_profile_widget.py`, `src/data/genres.py`.
- **Tiers:** no model involved.
- **Tests:** defaults with nothing set; values survive save and load; an old
  project with no readiness file still opens and uses the default; a novella's route is kept separately.
- **Done when:** the route can be set, saved and read back.
