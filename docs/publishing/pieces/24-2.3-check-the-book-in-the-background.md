each later check appears on screen as it is added.

## The piece

- **The writer gets:** a **Check the book** button. It works through the
  chapters with the model, shows progress, fills the grid as each chapter
  finishes, and can be stopped. Stopping keeps what is done.
- **Build:** a worker using the existing background pattern; changed chapters
  only, thanks to the cache.
- **Time:** four stages across forty chapters is about 160 model calls, which
  can take hours on a local or home-server model. Show an estimate before
  starting. Each chapter's result is saved as it finishes, so closing the app
  loses nothing and the next run carries on from where it stopped.
- **Tiers:** with no model, the button runs the scan and says so.
- **Tests:** stop mid-run keeps finished chapters; a model error on one chapter
  does not stop the rest.
- **Done when:** a full run completes on a test project and can be interrupted
  safely.

## Outcome

**Status:** done, 23 November 2026. Tested with a stand-in model; the writer
tries it with a real one.

**Built:**
- **Starting it:** **Check the book with the model…**, a link in the
  scorecard's note (no new button), shown when a model is configured and the
  book isn't fully judged. It uses the Critique's own analysis model.
- **The estimate:** chapters to judge (changed, or never judged), about how
  many requests, and roughly how long on a cloud or a local model
  (`src/ui/scorecard_model_run.py`, `readiness.model_work`).
- **While it runs:**
  - Check readiness becomes **Stop**.
  - The grid fills as each chapter finishes (`book_report(partial=)`, sent
    through a new `Task.send` / `run_background(on_data=)` in the shared
    background helper).
  - Each chapter is saved as it finishes; stopping keeps them, and the next
    run carries on.
  - A model error on one chapter leaves that chapter's scan and the run goes
    on; that chapter is retried next time.
- **No model:** it runs the scan and says so.
- **The option, off by default:** "Also judge changed chapters in the
  background while I write". Every 5 minutes it judges whatever changed,
  only when there is something to judge.

**Tests:** `tests/test_book_model_run.py` (6). They cover:
- stopping mid-run, then carrying on;
- an error on one chapter;
- the estimate;
- the scorecard run with Stop;
- no model;
- the background option.
