## The piece

- **The writer gets:** a **Check the book** button. It works through the
  chapters with the model, shows progress, fills the grid as each chapter
  finishes, and can be stopped. Stopping keeps what is done.
- **Build:** a worker using the existing background pattern; changed chapters
  only, thanks to the cache.
- **Time:** four stages across forty chapters is about 160 model calls, which
  can take hours on a local or home-server model. Show an estimate before
  starting. Each chapter's result is saved as it finishes, so closing the app
  loses nothing and the next run carries on from where it stopped.
- **Tiers:** with no model, the button runs the scan and says so.
- **Tests:** stop mid-run keeps finished chapters; a model error on one chapter
  does not stop the rest.
- **Done when:** a full run completes on a test project and can be interrupted
  safely.
