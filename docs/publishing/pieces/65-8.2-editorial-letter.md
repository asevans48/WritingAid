## Phase context

Start this phase when the server is running.

## The piece

- **The writer gets:** after a whole-book read, a two-page letter naming the
  three to five most important issues, each with its evidence and links to the
  chapters that show it.
- **Parity with:** ProWritingAid's manuscript analysis.
- **Covers:** the seven elements Editors Canada lists for a manuscript
  evaluation: characterisation, dialogue, setting, plot, structure, voice and
  tone. One letter per manuscript, so a novella gets its own.
- **Tiers:** without a model, the letter is assembled from the scorecard's worst
  results, in the same layout. With a model, it is written from the chapter
  reports and reverse outlines, not from the full text, so it fits any model.
- **Done when:** the letter's points link to real chapters and match the
  scorecard.
