## Phase context

Phase F makes the app work for stories that are not novels, **keeping every
story feature**: plot, characters, world, critique, the Improve window, Read
Aloud, the Studio. Agreed with the writer on 26 November 2026 (README
decision 18):

- **Kinds.** A project has a kind, chosen when it is created and changeable
  later: **Novel** (novels and novellas, as today, and the default for every
  existing project), **Video series**, **Podcast**, **Editorial series**,
  **Journalism**.
- **Same shape for every kind.** A project still holds a main manuscript,
  novellas and chapters. A kind changes the words on screen (set by the
  kind, editable per project), which checks and goals apply, and what
  publishing prepares. A chapter is one video, one episode or one part.
- **Nothing a novelist has changes.** A Novel project looks and behaves
  exactly as it does before this phase (rule 11). Every test of today's
  behaviour keeps passing unchanged.
- **Phase F comes after the final sweep (9.1).** Sending anything to a site
  (YouTube and others) stays a later integration (decision 7); this phase
  prepares the material.

## The piece

- **Why:** a sentence that reads well can be hard to say and hard to
  follow by ear.
- **The writer gets**, for Video series and Podcast projects, checks that
  need no model:
  - sentences too long to say in one breath, and too many clauses before
    the point;
  - hard-to-say runs (tongue-twisters, repeated sounds, stacked
    consonants);
  - numbers, dates, symbols, abbreviations and names that read badly
    aloud, with a say-it-this-way suggestion;
  - words that sound alike and could be misheard;
  - a listener losing the thread: a "he" or "it" far from its name,
    brackets and asides.
- **Listening is the main review** for these kinds: Read Aloud and
  Listen and mark are offered first on the Companion's next-step card,
  and marks become notes as today (6.2).
- Each check meets the four-in-five target (decision 3) on a set of real
  scripts before it is on by default; until measured it is offered, off.
  Put the measurement in *Outcome*.
- Flags use the existing hover card, Fix all, "Not a problem" and the
  Improve window; no new screen.

## Tests

- Each check on made-up lines that should and should not flag.
- None runs in a Novel project unless the writer turns it on.
- Cues and speaker labels are not flagged.
