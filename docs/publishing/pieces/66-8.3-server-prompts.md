## Phase context

Start this phase when the server is running.

## The piece

- **Why now:** this is the deferred work on prompts for the 120B server.
- **Do:** test the existing prompts on the server model, record where it does
  better with fuller context, and add a "large model" prompt size alongside the
  compact and standard ones where that helps.
- **Done when:** the server's results are at least as good as the general
  model's on a set of sample chapters, with the comparison written down.

## What has changed since this brief was written

_Added 24 November 2026, after phase 3, D.3 and 2.5 were built. Read the Outcome of each piece named here._

- **Measure, do not judge by eye:** `scripts/measure_misses.py --model
  --editor` gives caught and missed counts and false flags on clean
  passages. Run it against the server model and the general model and put
  both tables in the comparison.

## Build notes

_Added 24 November 2026 so a fresh session can finish this piece without searching. Names were checked against the code on that date; if one has moved, find it with a search and say so in Outcome._

- **Read first:** where prompts choose their size: `is_local_llm` and the
  `compact` flag in `src/ai/companion.py`, `src/ai/proofread.py`,
  `src/ai/editorial_letter.py`, `src/ai/voice_profile.py` and
  `src/ai/chapter_analysis_agent.py`.
- **Build:** one function that returns the prompt size for a model
  ("compact", "standard", "large"), used by those call sites in place of
  the scattered `compact` test. "Large" is chosen only for the server model.
- **Existing behaviour is unchanged** for local and cloud models: same
  prompts, same size.
- **Output:** `docs/publishing/server_prompts.md` with the comparison.
