## The piece

- **Why it matters more than it looks:** the app cannot plug into Word or Google
  Docs the way ProWritingAid does, so moving a manuscript in and out cleanly
  is how it lives alongside them. Check import from Word as well as export.
- **Standard:** William Shunn's novel manuscript format for agent submissions,
  as summarised under Format in [background.md](../background.md#what-publishable-means-here). Read the remaining rules
  (font, spacing, margins, indent, italics) from his novel guide in this piece.
- **Already there:** the exporter has Word, Kindle, Barnes & Noble and
  publisher-ready exports, and the Publishing tab has publish buttons for
  Kindle and Barnes & Noble. Check and correct these; do not add parallel
  ones.
- **Do:** compare what `src/export/manuscript_exporter.py` produces with
  that format and with the stores' requirements for self-publishing. Fix the differences. The export screen offers the format
  that matches the publishing goal first.
- **Done when:** an exported file passes a written checklist for each route.

## Outcome

**Built 24 November 2026.** The checklists are in [export_checklist.md](../export_checklist.md). Each line has its source and the test that checks it on a real exported file.

**Found and fixed: things that lost or damaged the writer's text**

1. **Importing from Word wiped the chapter without asking, and it could not be undone.**
   - `import_from_docx` called `self.clear()`, which also clears the undo history.
   - Now the import asks first when the chapter has text, with Cancel as the default (new `src/ui/import_guard.py`).
   - The replacement is one undo step, and the success message says Ctrl+Z puts the old text back.
2. **Italics and headings imported from Word were lost on save.**
   - They were put into the editor as display formatting, but the editor saves Markdown.
   - They now become Markdown (`*…*`, `**…**`, `## …`), through new `src/export/docx_import.py`.
3. **Every whole-book export wrote italics as asterisks.**
   - Word, EPUB, RTF, plain text and ODT all showed `*three*` instead of italics.
   - Now:
     - Word and EPUB use real italics and bold;
     - RTF uses `\i`/`\b`;
     - plain text and ODT drop the markers.
4. **The EPUB was not valid XHTML when the prose had "&" or "<".**
   - The text was not escaped, so a store would reject the file. It is escaped now.
   - Two smaller EPUB problems were fixed at the same time:
     - the identifier is now a stable `urn:uuid` (it was "id-<title>");
     - chapter file names are now numbered by position, not by `chapter.number`, which could repeat.

**Standard manuscript format** (Export Publisher Ready; new `src/export/standard_manuscript.py`):

- **Title page:** the author top left; the title about halfway down with "A Novel by …" or "A Novella by …" from the publishing goal; "about N words" counted from the text.
- **Running header:** "Surname / Title / N", numbered from 1 on the first page of text. The title page is its own section, with no header.
- **Body:** Times New Roman 12, double-spaced, half-inch indents, no extra space between paragraphs, ragged right, 1-inch margins.
- **Chapters:** each on a new page, the heading about a third down, centered in the body font ("Chapter N", then the title).
- **Scene breaks:** a centered "#".
