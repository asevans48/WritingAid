## The piece

- **Parity with:** ProWritingAid's character analysis.
- **The writer gets:** for each main character: which chapters they appear in,
  how much they speak, whether their way of speaking stays consistent, and
  (with a model) how they change across the book.
- **Uses:** `dialogue_craft.speech_profiles`, `dialogue_speakers`, the character
  entries, and `personality_assessor` if 0.1 finds it fits.
- **Where:** on the existing Characters screen, as a section on each character.
  No new tab.
- **Tiers:** presence, speech share and speech consistency need no model. The
  arc needs one.
- **Done when:** a character who vanishes for ten chapters, and one whose speech
  changes without cause, are both visible.

## Build notes

_Added 24 November 2026 so a fresh session can finish this piece without searching. Names were checked against the code on that date; if one has moved, find it with a search and say so in Outcome._

- **Read first:** `speech_profiles` in `src/ai/dialogue_craft.py`;
  `attribute_lines` in `src/ai/dialogue_speakers.py`; the `character_threads`
  check in `src/ai/readiness_checks/editor.py`; `src/ui/characters_widget.py`
  (where a character's sections are built); `src/ai/personality_assessor.py`.
- **Build:** a new small module that returns, per character: chapters
  present, lines spoken and share, and a consistency note. The Characters
  screen gets one collapsible section that shows it (`CollapsibleSection`
  from `ui_kit`), closed by default.
- **Cache by chapter hash,** as the readiness engine does, so opening a
  character does not re-read the book.
- **Tests:** a character absent for ten chapters is shown as absent; a
  character whose sentence length or contractions change sharply is marked;
  with no model the arc part says "needs a model".
