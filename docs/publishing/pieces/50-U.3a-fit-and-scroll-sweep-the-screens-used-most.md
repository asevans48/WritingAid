## The piece

- **This session:** the manuscript editor and its side panel, Suggestions,
  Rephrase, the critique tab, the style panel and Settings.
- **Do:** run the harness over the app's existing windows and dialogs, a group
  at a time. Fix what fails rule 12: add scrolling where content is squeezed
  or cut off, open windows within the screen, remove fixed heights on text.
- **Order:** the screens a writer uses most first: the manuscript editor and its
  side panel, Suggestions, Rephrase, the critique tab, the style panel,
  Settings. Then the rest.
- **Limit:** layout only. No change to what a screen does.
- **Done when:** the group passes the harness at all sizes. Repeat per group.

## Review notes

_The writer's changes to this brief, made before the session starts._

- **Done ahead (23 November 2026, at the writer's request):** narrow buttons
  that drew blank. The app's style gives every push button 16 px of side
  padding, so 33 buttons capped at 20–48 px showed no symbol.
  - `ui_kit.compact_button` now drops that padding on each one, and the Plot
    tab's arrow toggles are 24 px.
  - `tests/test_compact_buttons.py` fails if a new narrow button lacks it.
  - The harness now draws with the app's style sheet and flags any button
    narrower than its label.
  - Still open for this piece: the Write side panels and Video Studio need
    more than 1024 px.
