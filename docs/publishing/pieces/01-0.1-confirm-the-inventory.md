## The piece

- **Why:** the table in [inventory.md](../inventory.md) was built from
  summaries. Later pieces name functions from it, so it has to be right.
- **Do:** read each module in the table. For each, record the function to call,
  what it returns, whether it needs a model, and roughly how long it takes on a
  full chapter. Rewrite [inventory.md](../inventory.md) with those facts, and
  correct the *Uses* and *Read first* lines in the phase 1 pieces (1.3 to 1.6).
- **Also confirm:** how a project lists its manuscripts (main and novellas) and
  their chapters, since readiness works per manuscript; and the
  report-by-report table in [background.md](../background.md), marking each
  "likely" as yes or no.
- **Also record:** how the editor's highlighter exposes its flags for a chapter
  that is not open, since the engine must check every chapter.
- **Done when:** every check in phase 1 names a real function, the inventory
  file is corrected, and the gaps are listed in *Outcome*. Expected gaps: scene purpose, point of view, whole-book voice drift.
