## The piece

- **This session: design only. No code.** Write into this file under *Design*:
  where job state is stored, how a job resumes after a restart, what happens
  when the server is unreachable part-way, and how progress is shown without
  a new window. Then stop for review.
- **The writer gets:** long reads run as a job that keeps going with the window
  closed, shows its progress, can be paused, and resumes after a restart.
- **Design first:** where job state is stored, how a job resumes, and what
  happens if the server is unreachable part-way. Review before coding.
- **Build:** one job type to start with, the whole-book check from 2.3.
- **Tests:** a job interrupted half-way resumes from the next chapter; a server
  that goes away pauses the job with a clear message.
- **Done when:** a whole-book check started in the evening is finished in the
  morning.
