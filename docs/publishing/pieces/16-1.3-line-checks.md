## The piece

- **Adds checks:** repetition and echoes, filler and weak intensifiers, sentence
  variety, passive voice, adverbs, clichés, sticky sentences.
- **Uses, without rewriting them** (confirmed in 0.1; see the
  [inventory](../inventory.md)). This piece only connects them to the
  readiness report:
  - **Passive voice, adverbs, clichés, sticky sentences, echoes, and
    filler and weak intensifiers:** `style_checks.analyze_document(text)`
    then `style_checks.summarize(issues, words)`. The kinds are `passive`,
    `adverb`, `cliche`, `sticky_sentence`, `echo`, `intensifier` (this list
    holds the filler words: just, actually, basically, literally) and
    `wordy`. No model; about 13 ms a chapter.
  - **Repetition (overused words and repeated phrases):** `OveruseDetector`
    in `src/utils/overuse.py` (`update_cache`, then
    `analyze_text` / `analyze_phrases`). No model; about 7 ms. With a model,
    `repetition_judge.judge(llm, items)` decides which light repeats weaken
    the writing; the items come from `OveruseDetector.review_items()`.
  - **Sentence variety:** `style_checks` does not measure it. Use
    `ProWritingAnalyzer().analyze(text).sentence_length_score`
    (`src/utils/writing_stats.py`). R.4 will settle on one analyser; until
    then, use this field and note it in *Outcome*.
  - Import the checkers from `src/utils/` (moved there by R.3), not from
    `enhanced_text_editor.py`.
- **Thresholds:** stated per 1,000 words and kept in one table in
  `readiness.py`. P.3 later replaces them with genre figures.
- **Tests:** a chapter written to trip each check, and a clean one that trips
  none.
- **Done when:** the checks appear in the chapter report and on the scorecard.

## Outcome

**Status:** done, 23 November 2026 (with 1.4–1.6). Scan tier.

**Checks** (`src/ai/readiness_checks/line.py`), each counting what the editor
shows with that check on (`CheckContext.style_flags` runs the editor's own
style rules, so the writer's ignored flags, kept kinds and the dialogue rule
apply; repetition uses the editor's overuse flags):

- **Repeated words and phrases** (`repetition`). Published chapters show
  about 130 per 1,000 words as a scan, so it is `needs_model`: shown, not in
  the figure, until a model judges which repeats weaken the writing (1.7,
  `repetition_judge`).
- **Echoes**, **filler and weak intensifiers** (`intensifier` + `wordy`),
  **passive voice**, **adverbs**, **clichés**, **sticky sentences**.
- **Sentence variety**: `ProWritingAnalyzer().analyze(text).sentence_length_score`
  (R.4 kept it) against the genre profile's `variety_score_target`; the cell
  shows the score. Under 8 sentences it doesn't apply. On real published
  chapters the score sits at 100, so it catches only flat prose.

**Thresholds:** one table, `readiness.THRESHOLDS` (`THRESHOLDS_VERSION` 2).
The line figures were set from 29 real published chapters (three from each
Q.1 book, `scripts/calibrate_readiness.py`): "needs work" starts just above
their 90th percentile, so a published chapter normally reads as ready (89–100%
ready on every line check). P.3 replaces them with genre figures.

**Tests:** `tests/test_readiness_checks.py`: a chapter written to trip each
check and a clean one that trips none; the passive count equals the editor's
underlines; a "keep" rule in the style sheet empties the adverbs check.
