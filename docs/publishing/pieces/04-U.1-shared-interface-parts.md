## The piece

- **Why:** nine windows already contain their own copy of "open no larger than
  the screen", and newer panels set colours by hand. Shared parts make every
  later screen consistent and cheaper to build.
- **Build:** new `src/ui/ui_kit.py` with:
  - `fit_to_screen(window, width, height)` and `remember_geometry(window, key)`,
    which restores size, position and screen, and falls back to a visible
    screen.
  - `scrollable(widget)`, wrapping content in a scroll area the standard way.
  - `CollapsibleSection`, moved from the Companion and still importable from
    its old place.
  - A card, a status chip, a section header, a primary button and an empty
    state.
  - Colour names for each stage and each kind of problem, taken from
    `src/ui/styles.py` and `style_checks.KINDS`.
  - A helper that reports whether the window is narrow, normal or wide.
- **Read first:** `src/ui/styles.py`, `CollapsibleSection` in
  `src/ui/companion_panel.py`, `_fit_to_screen` in
  `src/ui/passage_critique_dialog.py`.
- **Backwards compatible:** nothing existing changes appearance in this piece.
  Existing screens adopt the kit in U.3 or when a piece touches them.
- **Done when:** the kit exists with tests, and Suggestions and the Companion
  use it with no visible change.

- **Data safety:** `remember_geometry` stores window positions only. Moving
  `CollapsibleSection` does not change how open and closed sections are
  recorded for a project.

## Outcome

**Status:** done. Suggestions and the Companion use the kit with no visible
change, confirmed pixel for pixel.

**New module `src/ui/ui_kit.py`:**

- **Fitting the screen:**
  - `fit_to_screen(window, width, height, *, min_width=480, min_height=360,
    margin_x=40, margin_y=60)` resizes a window to no larger than its
    screen. The defaults are Suggestions' old numbers.
  - `remember_geometry(window, key, default_size=None)` restores the size,
    position and screen saved under `key`, and records them on close or
    hide. If the monitor is gone or nothing was saved, the window is fitted
    and centred on a visible screen instead. A damaged saved value is
    ignored. `save_geometry(window, key)` records them by hand.
  - `size_class(widget)` returns `"narrow"` (window under 1,200 px wide),
    `"normal"`, or `"wide"` (2,000 px and up).
- **Scrolling:** `scrollable(content, frame=False)` wraps content in a scroll
  area that resizes with it and shows bars only when needed.
- **Parts:**
  - `CollapsibleSection`, moved here from the Companion and still
    importable from `src.ui.companion_panel`; it is the same class;
  - `section_header(text)`;
  - `card()`, a bordered `QFrame` with a vertical layout;
  - `status_chip(text, kind)`;
  - `primary_button(text)`, the screen's default action, in the accent
    colour;
  - `empty_state(text)`.

  None of them sets a fixed height (tested).
- **Colours:**
  - `PALETTE` is `styles.COLORS`.
  - `FLAG_COLOURS` holds the editor's spelling, grammar, overuse, repeated
    phrase and style colours, now kept only here. `ErrorCard.COLORS` points
    at it.
  - `PROBLEM_COLOURS` is the flag colours plus each style check's own
    colour from `style_checks.KINDS`.
  - `STAGE_COLOURS` gives Structure, Scene, Line, Copyedit and Proof,
    taken from the existing palette (primary, info, warning, success,
    accent).
  - `colour_for(kind)` looks any of these up.

**Changed:**

- `src/ui/styles.py`: `COLORS` gains named light-panel colours (`surface`,
  `surface_muted`, `surface_hover`, `border`, `border_strong`, `ink`,
  `ink_soft`, `ink_faint`, `primary_tint`, `primary_ink`). These are the
  values the newer panels set by hand. No existing value changed.
- `src/ui/companion_panel.py`: `CollapsibleSection` and the section
  divider now come from the kit, about 70 lines lighter.
- `src/ui/passage_critique_dialog.py` (Suggestions): `_fit_to_screen` and
  the scroll area call the kit. The method keeps its name for any other
  caller.
- `src/ui/enhanced_text_editor.py`: one line. `ErrorCard.COLORS` is
  `ui_kit.FLAG_COLOURS`, with the same values, so there is a single copy.
- `tests/conftest.py`: window positions go to a throwaway file in every
  test (rule 15).

**Checks:**

- `tests/test_ui_kit.py` has 15 tests, all passing:
  - fitting and its minimum size;
  - size classes;
  - a window comes back to the same size and place;
  - a missing monitor or a damaged saved value is handled;
  - scrolling;
  - both import paths give the same class;
  - opening and closing a section;
  - no fixed heights;
  - colours match `KINDS`, and the editor uses the kit's flag colours.
- The Companion and Suggestions tests pass unchanged.
- Full suite: 967 passed, plus the same 4 `test_overuse_context.py` failures
  that were failing before.
- **No visible change:** Suggestions and the Companion were drawn offscreen
  at 1024 × 600, 1440 × 900 and 2560 × 1440, and at 150% scaling, before
  and after the change. All 12 pairs are pixel-identical, and two runs of
  the "before" drawing were identical too, so the comparison is sound.
  Suggestions opens at the same fitted size (760 × 740; 493 × 473 at
  150%).

**Stored data:** `remember_geometry` keeps window positions in
`QSettings("WritingAid", "WindowGeometry")`, positions only. Nothing uses it
yet; screens adopt it in U.3. How the Companion records open and closed
sections is unchanged.

**Left out, as the brief says:** the ten Video Studio windows with their
own fit-to-screen code (`src/ui/video_studio/`) adopt the kit in U.3, or
when a piece next touches them.

**For the next pieces:** build new screens from the kit. U.2's harness can
reuse this piece's approach: draw offscreen at each size, then compare or
save the images (the script lived in the session's scratch folder, not the
