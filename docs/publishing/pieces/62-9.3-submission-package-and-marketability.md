## The piece

- **Where:** the existing Publishing tab (`src/ui/agent_manager_widget.py`),
  which already holds literary agent contacts and composes emails to them.
  The package is added there. No new screen.
- **Parity with:** ProWritingAid's marketability analysis.
- **Also gives:** who the book is for and where it sits among comparable titles,
  drawn from the genre list and the manuscript.
- **The writer gets:** drafts of a synopsis, a query letter and a blurb, plus
  comp titles from the genre list.
- **Tiers:** without a model, a filled-in template built from the plot and story
  memory. With one, drafts in the writer's voice that the writer edits.
- **Done when:** all three documents can be produced and exported.

## Build notes

_Added 24 November 2026 so a fresh session can finish this piece without searching. Names were checked against the code on that date; if one has moved, find it with a search and say so in Outcome._

- **Read first:** `src/ui/agent_manager_widget.py` (`AgentManagerWidget`,
  `_compose_email`); `assemble` in `src/ai/editorial_letter.py` (how a
  document is built without a model and improved with one);
  `src/data/conlit_loader.py` (the genre list).
- **Build:** a new small module that produces the three documents from the
  plot, the story memory and the style sheet; a "Submission package"
  section on the Publishing tab with the three drafts, each editable and
  saved in a per-project file. Export uses the existing exporter.
- **Comp titles** come from the genre list as candidates the writer picks
  from. The app does not claim a book is comparable.
- **Tests** use a fake model: the template version is complete with no
  model; drafts are saved, reloaded and exported; an older app version
  ignores the new file.
