## Phase context

Each of these lowers the counts recorded in 0.2. All follow rule 11:

- Each piece starts with a **capability checklist** of everything the old
  screen can do, and is not done until each item has a home in the new one.
- The replacement is built **alongside** the old screen. The old one is retired
  in a separate small step, after you have used the new one on both projects
  and agreed.
- Anything moved leaves a pointer, and shortcuts keep working.

## The piece

- **This session: design only. No code.** Read the three existing windows and
  write into this file under *Design*: the capability checklist for each
  (everything it can do today), which parts are truly shared, what each tab
  needs that the others do not, and how the existing classes become thin
  wrappers. Then stop for review.
- **The writer gets:** one window for help with a passage, replacing three.
  Tabs along the top: **Suggestions**, **Rephrase**, **Expand**, **Critique**.
  The lower half is shared: the options, an editable preview, the changes
  from the original, the rating buttons, and "Talk it through".
- **Design first:** which parts of the three existing windows are truly the
  same, and what each tab needs that the others do not. Review before coding.
- **Build:** a shared window in a new module. Each existing tool supplies its
  options to it. The existing windows' classes remain as thin wrappers, so
  every place that opens them keeps working.
- **Read first:** `src/ui/passage_critique_dialog.py`, `src/ui/rephrase_dialog.py`,
  `ExpandStatementDialog` in `src/ui/overdescription_panel.py`,
  `src/ui/rewrite_chat_panel.py`.
- **Each tool keeps its own model,** as configured today (rule 2).
- **Risk:** Rephrase is the largest of the three and has its own tests. If the
  merge threatens its behaviour, stop at Suggestions plus Expand and report.
- **Done when:** one window opens from every place the three did, existing tests
  pass, and it fits 1024 × 600 with scrolling.

**Agreed in 0.2:** the merge goes ahead, with no feature cut. Already shared
today: the conversation panel (`ConversationPanel` in
`src/ui/rewrite_chat_panel.py`, used by Suggestions and Rephrase) and
`OverdescriptionPanel` (used by Suggestions, the editor and the Critique). AI
Thesaurus (`WorldWordDialog`) and Ask (`FlagChatDialog`) stay their own
windows; the design may note how they could join later. Every place that opens
the three windows today (listed in [screens.md](../screens.md), rows 6 to 8)
must open the merged window on the right tab.
