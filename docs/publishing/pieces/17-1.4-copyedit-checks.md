## The piece

- **Adds checks:** consistency (names, hyphenation, numbers) and style sheet
  breaks.
- **Uses** (confirmed in 0.1):
  - `ConsistencyChecker(chapters, canon_names, is_known_word=None,
    ignored=()).run()` in `src/utils/consistency_checks.py`, which returns
    `List[ConsistencyGroup]`. `chapters` is `[(chapter_id, title, text)]`
    for one manuscript (`project.iter_manuscripts()`, not
    `project.manuscript`). Build the canon names the way
    `MainWindow._canon_names` does. No model; about 0.4 s for 20 chapters,
    so run it once per manuscript, not once per chapter, and attribute each
    group's occurrences to their chapters.
  - `style_sheet.preference_issues(project, paragraph)` in
    `src/ai/style_sheet.py`, per paragraph. It returns `StyleIssue`s of
    kind `"preference"`. No model; instant.
- **Done when:** both checks appear in the report and the dialog is unchanged.

## Outcome

**Status:** done, 23 November 2026. The Consistency dialog is unchanged in
behaviour except for one fix (below).

**Checks** (`src/ai/readiness_checks/copyedit.py`):

- **Consistency** (`consistency`): `ConsistencyChecker` run **once per
  manuscript** (`Book.lazy`), with the same names as `MainWindow._canon_names`
  plus characters' other names. Each inconsistency found in a chapter is one
  item there (the first place; the reason says how many), with the usual form
  as the fix. Capitalization groups (a judgement) are left out. It depends on
  every chapter, so its cache key includes them all (`book_wide`). Threshold:
  1 ready, 4+ a problem.
- **Style sheet breaks** (`style_sheet`): the editor's preference flags
  (`style_sheet.preference_issues` through the editor's rules). Not shown
  until the style sheet has a prefer or avoid rule.

**Bug fixed in `consistency_checks.py`** (also affects Edit → Consistency):
names ending in "s" were reported as misspelt ("Dorcas — also spelled
Dorca"), because the possessive was stripped with `rstrip("'’s")`, which
removes any final s. Only a real possessive is dropped now. On published
chapters this took consistency from 37% to 75% "ready"; what remains is
real (mantel-shelf/mantelshelf, whilst/while).

**For the writer:** "spelling and grammar left" stays strict (0.5 per 1,000
words is ready), as designed: every flag is fixable or can be added to the
dictionary. On the old published books it is high only because of British
spellings, dialect, Latin and the known accent bug ("Ántonia" checked as
"ntonia"), which P.5 fixes; a grammar false alarm on "I was not" is noted
for P.5 too.
