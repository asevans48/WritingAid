## Phase context

Each of these changes no behaviour. They are placed where they make the next
feature pieces smaller and safer. All keep old import paths working and pass
the existing tests unchanged.

## The piece

- **Why:** the spelling checker, the overuse detector, the style analyser and
  the grammar checker live inside the 5,700-line editor file. The readiness
  engine and the benchmark must run them on chapters that are not open, which
  is not possible while they are tied to the editor.
- **Do:** move `SpellChecker`, `OveruseDetector`, `ProWritingAnalyzer`,
  `WritingStats` and `GrammarChecker` into modules under `src/utils/`, with no
  Qt in them. The editor imports them from there, and the old names still
  import from the editor file.
- **Limit:** move only. No change to what any check finds.
- **Keep working:** each project's own dictionary words, ignored words and
  ignored rules, and the names taken from its characters and world.
- **Done when:** a chapter can be checked from a plain script with no window,
  the editor behaves the same, and the editor file is about 1,500 lines
  shorter.

- **Data safety:** the checkers hold things the writer built up: each project's
  dictionary words, ignored words and ignored rules, and the style issues
  marked as ignored. Find where each is kept before moving anything, and
  list them in *Outcome*. After the move they are read from and written to
  the same place under the same names. Add a test that loads a project with
  custom words and ignored rules, and shows they are still honoured.

## Outcome

**Status:** done. Move only: the moved code is character-for-character the
same as before.

**Moved** out of `src/ui/enhanced_text_editor.py`, into new modules with no
Qt in them:

| Module | What | Lines |
|---|---|---|
| `src/utils/spell_checker.py` | `SpellChecker`, `_apos`, the shared pyspellchecker dictionary | 545 |
| `src/utils/overuse.py` | `OveruseDetector`, `_sentence_at`, `_sentences_with` | 684 |
| `src/utils/writing_stats.py` | `WritingStats`, `ProWritingAnalyzer` | 557 |
| `src/utils/grammar_checker.py` | `GrammarChecker` | 43 |

**The editor file** goes from 5,720 to 3,940 lines (1,780 shorter). In place
of the classes it has one block of imports, so every existing
`from src.ui.enhanced_text_editor import SpellChecker` (and the others,
`_apos` included) gives the same class as before. The Qt parts stay in the
editor: the highlighter, its workers, `ErrorCard` and the editor itself.

**How it was checked that nothing changed:**

- Each new module's code was compared with the matching lines of the
  original file: identical, all four.
- Full suite: 983 passed, plus the same 4 `test_overuse_context.py`
  failures that were failing before. No existing test changed.
- The screen harness gave 68 of 68 images identical to the run before R.2,
  with the same counts.
- `check_project_safety.py` on both projects: safe, with the same counts as
  the 0.3 baseline.

**Where the writer's data is kept** (found before moving; all unchanged):

| What | Where it is stored | Read and written by |
|---|---|---|
| "Add to dictionary" words | `project.dictionary.words`, in the project file | written by `ChapterEditor._save_word_to_project_dictionary`; read by `EnhancedTextEditor.set_project_vocabulary` into `SpellChecker.set_project_words` |
| Character and world names | `project.characters`, and the world elements found by `canon_index.collect_world_entities` | the same reader, plus `OveruseDetector.set_names` |
| Allowed words and kept style kinds | `project.style_sheet`, in the project file | `style_sheet.allowed_words` and `kept_kinds`, read by the highlighter and the overuse detector |
| Ignored words, phrases, grammar rules and style issues | in memory, for the session: `OveruseDetector._ignored_words` and `_ignored_phrases`, `GrammarChecker._ignored_rules`, the highlighter's `_ignored_words` and `_style_ignored` | the same objects as before |
| Words added with `SpellChecker.add_word` | in memory (`_custom_words`), and saved through the project dictionary above | unchanged |

**Tests:** `tests/test_checkers_standalone.py`, 4 tests:

- **a chapter checked from a plain script with no window:** spelling,
  overuse, statistics and grammar run, and Qt is never loaded;
- **old import paths** give the same classes;
- **data safety:** a project with its own dictionary word, a character name
  and a style-sheet "allow" word is saved, reopened from disk, and checked.
  The dictionary word and the name are known, the allowed word is not
  flagged, and an unknown word still is;
- **ignored grammar rules and ignored overused words** are still honoured.

**Docs updated:** the inventory, piece 1.3 and `screens.md` now name the
new modules.

**For the next pieces:** import the checkers from `src/utils/`. The

chapter without a window. Only the editor's highlighter still needs Qt, and
