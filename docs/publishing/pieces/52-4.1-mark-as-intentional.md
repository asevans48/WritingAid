## The piece

- **The writer gets:** anywhere a quirk is flagged (fragments, dialect, an
  unusual rhythm), a **This is intentional** choice that adds it to the style
  sheet.
- **Builds on:** 3.3. This piece adds the choice to the editor's right-click
  menu and the scorecard's item list.
- **Done when:** a quirk marked intentional is never flagged again.

## Outcome

**Built 24 November 2026.** Waiting for the writer's review and the rule 15
safety check (before and after) on both projects: it writes the readiness
file and adds style sheet rules to the project file.

**What existed:** three ways to say "leave it", in one store (the readiness
file's `"dismissed"`): the Critique's "That's intended"
(`editor_pass.set_intended`, no `"as"`), the card's Not a problem
(`fix_queue.dismiss`, `"as": "not a problem"`), and the editor's Ignore /
Ignore this issue (this session only). Separately, the writer's style sheet
(`project.style_sheet`, the Companion's "Your style sheet"), which 💬 Ask →
"It's deliberate" already adds to. Missing: the right-click entry, and the
link between a dismissal and a style sheet line.

**Which style sheet.** The Build notes point at `story_ledger` too. That is
the model's record of facts, each tied to a quote, dropped when the words
change; a quirk is not a fact. So the line goes into the writer's own style
sheet, which the checks read (allowed words) and every model prompt sees
(`prompt_block`). No fourth store.

**What the writer gets:**

- **Right-click a flag** (Write tab, and the editor's own menu, via
  `add_flag_section`): **📌 This is intentional**, after Ignore. The flag
  goes at once, and is not raised again in any chapter of this project,
  after a restart, in the readiness report or the next-fix queue. The
  Companion's style sheet shows a line:
  - a spelling flag or a repeated word: "“teh” is a word — don't flag it";
  - anything else (a style flag such as a fragment, a grammar flag, a
    repeated phrase): "Intentional (Weak intensifiers): “very”".
- **Critique, "That's intended"**: the same function, so it now also adds
  the line. "Take that back" removes both.
- **Next-fix card**: after Not a problem, the status line offers "Undo ·
  It's intentional: add it to my style sheet". Undo then takes back both.
- **The style sheet line can be reworded** (double-click it in the
  Companion's list) **or deleted** (Delete, as before). Deleting it flags
  the quirk again. A rewording that reads as a rule ("allow vethari") becomes
  that rule; any other wording is kept as written.
- **The editor's brief** lists each quirk once, under "Intended (chapter)";
  plain notes in the style sheet now appear there with their text (they
  were printed as blank bullets).

**Code:**

- New `src/ai/intentional.py` (no Qt): `mark(project, key, text, reason,
  label, chapter, category=, word=, rule=True)` → (saved, rule);
