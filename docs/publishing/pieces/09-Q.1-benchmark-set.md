## Phase context

Nothing in the app says how often a check is right. This phase builds that
measure. Every later claim about quality rests on it.

## The piece

- **Build:** a folder of test passages with the right answers recorded:
  - **Seeded errors.** Clean passages with known mistakes inserted: spelling,
    agreement, confused words, punctuation, repeated words. The right answer is
    the list of insertions.
  - **Clean published prose.** Passages of well-edited fiction in several
    genres, from the corpora the app can already fetch. The right answer is
    that almost nothing should be flagged.
  - **Marked style passages.** A small hand-marked set for the style checks and
    the overly descriptive check, including deliberate fragments, dialect and
    dialogue, where a flag would be wrong.
- **Read first:** `src/data/corpus_adapters.py`, `src/data/corpus_catalog.py`,
  `tests/test_proofing.py`.
- **Tiers:** no model needed to build it.
- **Done when:** the set exists, is small enough to run in a few minutes, and
  its answers are stored beside the passages.
