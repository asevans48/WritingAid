## The piece

- **The writer gets:** each measure shown against published books in the book's
  genre, not against a fixed number. "Dialogue 31%; published thrillers 35 to
  50%."
- **Build:** extend the baseline the pacing analyser already uses to cover
  sentence length and variety, dialogue share, adverbs, passive voice,
  readability and chapter length. Computed once from the corpora and stored.
- **Read first:** `src/ai/pacing_analyzer.py`, `src/data/conlit_loader.py`.
- **Tiers:** no model. Without the corpus data, the fixed thresholds remain.
- **Done when:** the readiness thresholds come from the genre baseline where one
  exists.

## What has changed since this brief was written

_Added 24 November 2026, after phase 3, D.3 and 2.5 were built. Read the Outcome of each piece named here._

- **Failing checks now explain themselves** in the Critique: "What it looks
  for: …" from the check's `description` (2.5). When a threshold comes from
  the genre baseline, put the range in the result's message so the writer
  sees it there ("published thrillers 35 to 50%").
- **Stages matter:** the queue offers only the current stage's fixes (3.1,
  3.2). A measure with no place in the text never enters the queue; that is
  intended.

## Build notes

_Added 24 November 2026 so a fresh session can finish this piece without searching. Names were checked against the code on that date; if one has moved, find it with a search and say so in Outcome._

- **Read first:** `analyze_text`, `compare_to_genre` and `comparison_report`
  in `src/ai/pacing_analyzer.py`; `compute_genre_stats` and
  `get_genre_baseline` in `src/data/conlit_loader.py`; `Threshold` and
  `CheckSpec.threshold` in `src/ai/readiness.py`.
- **Build:** the baseline gains the listed measures where the corpus data
  has them. A check asks one function for its threshold: the genre range if
  there is one, else today's fixed number.
- **Results change when a threshold changes.** Raise the check's `version`
  so cached results are recomputed, and show before-and-after statuses on
  the benchmark in *Outcome*.
- **Existing projects:** a chapter that was "ready" must not turn to "a
  problem" silently. Where the genre range is stricter, the Critique says
  once that the comparison is now with the genre.
- **Tests:** with corpus data, a threshold comes from the genre; without, it
  is today's number exactly; the baseline file is computed once and reused.
