## The piece

- **Why:** the scorecard must count exactly what the editor underlines. The
  rules for *which* flags to show lived inside `WritingHighlighter.highlightBlock`
  (241 lines, 16 of them drawing), which needs Qt and so can't run on a
  worker thread.
- **Build:** move the deciding into a Qt-free module,
  `src/utils/editor_flags.py`; the highlighter calls it and only draws.
- **No behaviour change.** Checked by comparing every flag *and every drawn
  format* before and after, the Q.2 table, and the existing tests.
- **Data safety:** touches no stored data, name or layout.

## Outcome

**Status:** done, 23 November 2026. No behaviour change.

**Built** — `src/utils/editor_flags.py` (no Qt):

- `FlagRules`: the rules, moved unchanged from the highlighter
  (`style_issues_for`, `is_word_ignored`, `_word_intended`,
  `_probably_a_name`, `_starts_sentence`, `_should_check`), plus
  `paragraph_flags(text, block_number, block_position)` → (flags in drawing
  order, Focus's kept flags or None). `WritingHighlighter` now inherits
  `FlagRules`; `highlightBlock` asks `paragraph_flags` and only draws
  (it went from 241 lines to about 60). A grammar flag carries
  `draw_segments` (the parts not already under a spelling flag) and its
  `rule_id`.
- `FlagState`: the same rules with plain settings, for code with no editor;
  `from_highlighter(hl)` copies a live editor's settings, ignored words and
  LanguageTool results; `flags_for_text(text)` gives every flag with its
  paragraph offset.
- Shared set-up, so the editor and the engine can't drift apart:
  `new_checkers()` (the editor's three checkers, overuse reviewing light
  repeats), `project_vocabulary(project)` and `allowed_words(project)` (what
  `set_project_vocabulary` used), `state_for_project(project, base)`, and
  `languagetool_issues(paragraphs, engine)` (the batching `_GrammarWorker`
  did; it now calls this).
- `CheckMode`, `ErrorType`, `WritingError`, `issue_weight` moved here;
  `src.ui.enhanced_text_editor` still imports them (same objects), so every
  existing import works. `enhanced_text_editor.py` went from 3,949 to about
  3,600 lines.

**Checked unchanged:**

- Every flag and every drawn format (background, underline, font, Markdown
  formatting) over 35 renders: six benchmark chapters plus a sample with
  headings, dialogue and misspellings, each with all checks on, Focus,
  drafting, ignored words and a word being typed. Byte-identical before and
  after.
- Q.2 table identical, without and with LanguageTool.
- Full suite: no new failures.

**Tests:** `tests/test_editor_flags.py` (5): the engine sees exactly what the
editor shows, settings carry over, old imports are the same objects, the
module loads no Qt, and it runs on a worker thread.
