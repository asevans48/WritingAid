## The piece

- **Parity with:** ProWritingAid's plot analysis (pacing, structure, missing
  beats).
- **The writer gets:** the reverse outline next to the chapter's planned events,
  with planned events missing from the draft and drafted scenes missing from
  the plan both marked. One chart shows tension across the book.
- **Read first:** `src/ui/outline_panel.py`, `ChapterPlanning.events`.
- **Tiers:** without a model, the chart shows pacing figures instead of tension.
- **Done when:** a missing planned event and an unplanned scene are both visible.

## Build notes

_Added 24 November 2026 so a fresh session can finish this piece without searching. Names were checked against the code on that date; if one has moved, find it with a search and say so in Outcome._

- **Read first:** 7.1's Outcome; `ChapterPlanning.events` in
  `src/models/project.py`; `src/ui/outline_panel.py`.
- **Where:** in the Critique, in the reverse outline's section (decided for
  7.1): each scene with the planned event it matches beside it, unmatched
  ones on either side marked.
- **Matching without a model:** by names and distinctive words shared
  between a planned event's text and a scene. Show the match as a
  suggestion the writer can correct; store corrections in the readiness
  file under a new key.
- **The chart:** one small chart in the same section. No new window.
- **Tests:** a planned event with no scene and a scene with no event are
  both marked; a correction by the writer survives a restart.
